# Master laptop run — 931 → 951 → 971-990 → 991-1010 (one sitting)

Copy these FIVE files from `tools/patchers/` (the runner script sits
at the repo root) to the **bot root** on the laptop:

```
add_batch_931_950_heal.mjs
add_batch_951_970_wati.mjs
add_batch_971_990_combined.mjs
add_batch_991_1010_cloud_lang.mjs
run_931_1010.sh
```

Then run ONE command:

```
bash run_931_1010.sh
```

The script runs the four patchers in order, checks every SUMMARY
(warnings must be 0, no FAIL / NOT FOUND lines) and prints the next steps.
Expected totals on a clean laptop:

| Patcher | Expected |
|---|---|
| 931-950 heal | 10 applied, 0 already done, 0 warnings |
| 951-970 WATI | 10 applied, 0 already done, 0 warnings |
| 971-990 combined | 27 applied, 0 already done, 0 warnings |
| 991-1010 cloud+lang | 14 applied, 0 already done, 0 warnings |

Re-running is safe — every patcher is idempotent ("already done" skips),
so a half-applied laptop just shows smaller "applied" counts.

## 991-1010 extra prerequisite (only for the Cloud templates feature)

WhatsApp Cloud API env vars on the bot: `OMNIFLOW_WA_CLOUD_URL` +
`OMNIFLOW_WA_TOKEN` (360dialog tenants: `OMNIFLOW_WA_AUTH_HEADER=D360-API-KEY`
+ `OMNIFLOW_WA_AUTH_VALUE=<key>`). Without them, everything else still
works — only the Cloud templates card stays empty.
